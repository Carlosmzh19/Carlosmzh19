## Proyecto destacado

### [MCP-VMS-SO](https://github.com/Carlosmzh19/MCP-VMS-SO)

- **Qué resuelve:** administra máquinas virtuales VirtualBox (Windows y Linux) desde un agente MCP, sin abrir puertos adicionales en el anfitrión.
- **Cómo está hecho:** servidor Python con FastMCP sobre `ssh` y `scp` nativos; 156 herramientas tipadas, secretos en base64 y auditoría en logs.
- **Qué demuestra:** una integración de infraestructura segura, trazable y operable en lenguaje natural sin perder el control del sistema.
